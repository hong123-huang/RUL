# 定案組合消融：基線過強的原因與疊加式消融方案

更新：2026-09-30　對應進度頁：XJTU-SY 跨工況 RUL 消融進度

---

## 1. 問題

| 階 | 定案組合 平均 Score | ΔScore |
|---|---|---|
| S0 原始訊號 CNN | 0.5680 | — |
| S1 ＋FPT | 0.5542 | −0.014★ |
| S2 ＋EDL | 0.5671 | +0.013★ |
| S3 ＋SA（本文） | 0.5826 | +0.016★ |

本文方法只比 S0 高 0.015，而且中間一階是負的。

## 2. 原因分析

### 2.1 S0 並不是「原始訊號」基線，它已經帶著大部分的工程成果

目前的 S0 已經含有以下元件，而這些元件從未進入消融階梯：

| 已經在 S0 裡的東西 | 是否消融過 |
|---|---|
| rFFT 頻譜輸入 | 否（A1：`use_rfft` 沒接到開關） |
| 健康段抽稀 0.2 | 否 |
| 來源排除規則（1_5、2_4） | 否（屬資料協定） |
| C2 測試軸承 2_1 → 2_2 | 否（屬資料協定） |

進度頁的數據已經說明：這些資料端選擇給 S0 **+0.105**，給本文方法只有 **+0.008**。
也就是說，原本屬於「方法 vs. 基線」的差距，被資料協定吸收進基線了。
基線的名字叫「原始訊號 CNN」，但它其實是「頻譜 CNN ＋ 精選資料協定」。

### 2.2 FPT 是「使能元件」，單獨加入時沒有東西可以修

由現有數據可以拼出一個不完整的 2³ 因子表：

| FPT | EDL | SA | 平均 Score | 來源 |
|---|---|---|---|---|
| – | – | – | 0.5680 | 表 2 S0 |
| ✓ | – | – | 0.5542 | 表 2 S1 |
| ✓ | ✓ | – | 0.5671 | 表 2 S2 |
| ✓ | – | ✓ | 0.5620 | 表 3 S2' |
| ✓ | ✓ | ✓ | 0.5826 | 定案 |
| – | ✓ | ✓ | ≈0.5736 | 「不做 FPT」對照（0.5826 − 0.009） |
| – | ✓ | – | **缺** | 需補跑 |
| – | – | ✓ | **缺** | 需補跑 |

FPT 的效果隨其他元件而變號：

- 單獨加在 S0 上：**−0.014**
- 加在 EDL＋SA 上：**+0.009**

這是正的交互作用：FPT 自己的作用只是讓整體偏移由 +0.015 移到 −0.075（誤差散布 0.118 → 0.117 幾乎不變），
它的價值要透過 SA（需要 FPT 切出的退化階段）與 EDL 才表現出來。
把使能元件排在第一階，階梯一定會出現負值，這是**排序問題，不是方法問題**。

### 2.3 評估粒度太粗，剩餘空間很小

六個任務只用到三顆測試軸承（1_2、2_2、3_4），每顆出現兩次。
能展現對齊效果的困難軸承（例如 2_1，原始 CNN 對它偏移 +0.18）已經被換掉了。
S0 在 3/6 任務上已接近本文方法，剩餘可提升的空間本來就少。

### 2.4 Score 與 RMSE 最佳偏移不同

Score 最佳偏移約 −0.05，RMSE 最佳偏移為 0。任何「只移動偏移」的元件（FPT 正是如此）
都無法同時改善兩者。能同時改善三個指標的，只有**降低誤差散布**的方法。
這也是為什麼 12 種訓練端方法大多卡在雜訊內：它們主要影響偏移或特徵分佈，而散布（0.117）才是誤差的主體。

## 3. 疊加式消融方案（每一階都有 IEEE 文獻依據）

原則：階梯順序與測試軸承都**在跑結果之前**依規則決定，不做事後挑選。

### 方案 A　把 S0 還原成真正的原始訊號 CNN，rFFT 成為第一階

| 階 | 內容 | IEEE 依據 |
|---|---|---|
| S0 | 原始時域振動訊號 → 1D-CNN | Zhu, Chen, Peng, "Estimation of Bearing Remaining Useful Life Based on Multiscale Convolutional Neural Network," *IEEE Trans. Ind. Electron.*, 66(4), 3208–3216, 2019（CNN 直接由原始振動訊號映射到 RUL） |
| S1 | ＋rFFT 頻譜輸入 | Ren, Sun, Wang, Zhang, "Prediction of Bearing Remaining Useful Life With Deep Convolution Neural Network," *IEEE Access*, 6, 13041–13049, 2018（頻譜特徵輸入 CNN） |

這同時補上 A1（rFFT 從未消融），是論文本來就缺的一格，不是為了拉開差距而加的。
預期原始時域 CNN 在跨工況下明顯較差（時域波形受轉速、負載直接影響），但**必須實測**。
健康段抽稀、cosine LR 等訓練設定視為所有階共用的訓練協定，不列入階梯，並在實驗設定中寫明。

GPU：約 3 小時（一次 S0-時域）。

### 方案 B　補齊 2³ 因子表，用「前向逐步選擇」決定順序

補跑兩格：`S0+EDL`、`S0+SA（無 FPT）`，約 7 小時。之後：

1. 預先登記規則：**從 S0 開始，每一步加入邊際增益最大的元件**（forward stepwise）。
2. 用 `tools/factorial_ablation.py` 由因子表自動算出順序與每階 Δ。
3. 附錄放完整 8 格因子表與各元件的平均主效應，證明順序不是挑出來的。

依 2.2 的交互作用，FPT 很可能會排在最後一階（EDL＋SA 之後 +0.009）。
正文可以直接寫：「FPT 為 SA 提供退化階段邊界，因此在 SA 之後才顯現效益」，這是機制說明，不是藉口。

另外請在正文或附錄加一張 **leave-one-out 表**（從完整模型拿掉一個元件），現有數據就能填：

| 模型 | 平均 Score | Δ vs. 完整 |
|---|---|---|
| 完整（FPT＋SA＋EDL） | 0.5826 | — |
| w/o FPT | ≈0.5736 | −0.009★ |
| w/o SA | 0.5671 | −0.016★ |
| w/o EDL | 0.5620 | −0.021★ |

三個元件拿掉都顯著變差，這是 IEEE 期刊最常見的消融呈現法，和疊加式階梯互補。
注意 w/o FPT 的 RMSE 反而好 0.035，必須在文中如實說明（Score 與 RMSE 的偏移取捨，見 2.4）。

### 方案 C　新增降低誤差散布的元件

由 2.4，剩餘的提升空間在「散布」而不在「偏移」。下列方法都直接作用在散布上：

| 優先 | 方法 | IEEE 依據 | 成本 | 說明 |
|---|---|---|---|---|
| 1 | **時序平滑**（因果移動平均／指數平滑） | Ren et al., *IEEE Access* 2018（同上，文中提出平滑法處理 RUL 預測不連續） | **0 GPU**，用既有預測即可 | 只用同一軸承「過去」的預測值，不用任何目標標籤，屬後處理而非校準；平滑參數必須在**來源驗證軸承**上決定 |
| 2 | 雙通道輸入（水平＋垂直） | Wang, Lei, Li, Li, "A Hybrid Prognostics Approach for Estimating Remaining Useful Life of Rolling Element Bearings," *IEEE Trans. Reliability*, 69(1), 2020（XJTU-SY 資料集論文） | 約 3.5 h | 若目前只用單一通道才適用 |
| 3 | SE 通道注意力 | Hu, Shen, Albanie, Sun, Wu, "Squeeze-and-Excitation Networks," *IEEE TPAMI*, 42(8), 2011–2023, 2020 | 約 3.5 h | 讓 CNN 自動加權頻帶；接在每個卷積區塊後 |
| 4 | 多尺度卷積 | Zhu et al., *IEEE TIE* 2019（同上） | 約 3.5 h | 平行多個卷積核大小 |

建議只做第 1 項，最多再加一項。時序平滑幾乎一定能降低散布（同時改善 Score／RMSE／MAE），
而且不需要重跑。注意：若要在階梯中加入 SE 或多尺度，它們是骨幹改動，必須放在階梯中並說明，
不能偷偷加到 S0 裡，否則會重演 2.1 的問題。

### 方案 D　評估協定（建議至少放在穩健性表）

目前 C2 測 2_2 是看過分數後選的（進度頁已註明）。建議增加一張表：
**目標工況的所有軸承都當測試軸承**（對齊仍只用無標籤資料），或至少同時報告 2_1 與 2_2。
這會移除「測試集挑選」的疑慮，而困難軸承正是對齊方法能展現效益的地方，差距通常會變大。

## 4. 建議的最終階梯（待實測）

```
S0  原始時域 CNN                         （Zhu, IEEE TIE 2019）
S1  ＋rFFT 頻譜                          （Ren, IEEE Access 2018）
S2  ＋第一個逐步選擇元件（EDL 或 SA）
S3  ＋第二個逐步選擇元件
S4  ＋FPT（預期在此顯現 +0.009）          （Wang, IEEE TR 2020 的 FPT 概念）
S5  ＋時序平滑                           （Ren, IEEE Access 2018）
```

## 5. 執行順序與 GPU 時間

| 步驟 | GPU | 產出 |
|---|---|---|
| 1. 用既有預測跑 `tools/smooth_predictions.py` | 0 | 平滑是否有效，立刻知道 |
| 2. 接上 `use_rfft` 開關，跑 S0-時域 | ≈3 h | 方案 A，同時補 A1 |
| 3. 補跑 `S0+EDL`、`S0+SA` | ≈7 h | 方案 B 因子表 |
| 4. `tools/factorial_ablation.py` 產生階梯 | 0 | 最終順序 |
| 5.（選做）全目標軸承評估 | ≈10 h | 方案 D |

步驟 2 的 S0-時域 其實要在「S0-時域 ＋ 各元件」上重建整條階梯才完全一致；
若 GPU 有限，可以只把 S0-時域 放在現有階梯最前面（S0-時域 → S0-rFFT → …），
並在文中說明後續各階都在頻譜輸入上。

## 6. 不建議做的事

- 為了讓階梯單調而事後挑測試軸承或排序。
- 把平滑參數用目標測試軸承調。
- 再試更多對齊損失：12 種訓練端方法已經證明偏移／分佈類方法在此設定已飽和。
